# 🌈 Papelería Arcoíris App

Aplicación Android en React Native + TypeScript para Papelería Arcoíris.

## Implementado
- 📸 Foto a PDF: cámara/galería, selección múltiple, revisión y PDF tamaño carta.
- 🗂️ Escaneo múltiple: cámara/galería, páginas múltiples, reordenamiento y PDF único.

## Dependencias principales
React Native, React Navigation, react-native-image-picker, react-native-html-to-pdf y react-native-fs.

## Instalación
```bash
npm install
npx react-native run-android
```

La carpeta Android debe generarse en el entorno React Native anfitrión antes de compilar el APK. La mejora IA queda preparada para conectarse mediante una API segura; mientras no haya API configurada, se conservan las imágenes originales.
